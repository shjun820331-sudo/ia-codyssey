# 부수입 가계부

과외, 앱테크, 중고거래, 보험 같은 부수입을 기록하고 월별 순수익과 아직 받을 돈을 한눈에 보는 웹 앱입니다.
빌드 과정 없이 **HTML + CSS + Vanilla JS + LocalStorage** 만으로 동작합니다.

## 실행 방법

```bash
cd side-income
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 더블클릭해서 열어도 동작합니다. GitHub Pages에 올리면 `/side-income/` 주소로 휴대폰에서 바로 쓸 수 있습니다.

## 홈 화면에 앱으로 설치하기 (PWA)

HTTPS 주소(GitHub Pages 등)로 열면 홈 화면에 앱으로 설치할 수 있습니다. 설치하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷이 없어도 실행됩니다.

- **Android (Chrome, 삼성 인터넷)**: 상단의 `앱 설치` 버튼, 또는 브라우저 메뉴 → `앱 설치` / `홈 화면에 추가`
- **iPhone (Safari)**: 아래쪽 공유 버튼(□↑) → `홈 화면에 추가` (앱 화면 상단에 안내 카드가 표시됩니다)
- **PC (Chrome, Edge)**: 주소창 오른쪽의 설치 아이콘

앱 파일을 수정해 다시 배포할 때는 `sw.js`의 `VERSION` 값을 올려야 설치된 앱도 새 버전으로 바뀝니다.

## 기능

| 영역 | 내용 |
| --- | --- |
| 기록 | 날짜 · 카테고리 · 금액 · 비용(선택) · 입금 상태 · 메모. 금액은 입력하는 대로 쉼표가 붙음 |
| 카테고리 | 과외 · 앱테크 · 중고거래 · 보험 · 받을돈 + `직접작성`(한 번 쓰면 목록에 저장) |
| 요약 | 월 순수익(들어온 돈 − 비용), 들어온 돈 / 비용 / 받을 예정, 연간 누적 순수익, 월 목표 달성률 |
| 받을 돈 | 달과 상관없이 아직 안 받은 돈을 모아서 표시, `받았어요` 한 번에 입금 처리(되돌리기 가능) |
| 카테고리별 | 이번 달 카테고리별 수입 막대 그래프와 비율 |
| 내역 | 월 이동, 카테고리 필터, 날짜별 묶음과 일별 합계. 누르면 수정·삭제(삭제 되돌리기 가능) |
| 백업 | 엑셀용 CSV 내보내기, JSON 백업 받기 / 불러오기 |

순수익에는 실제로 받은 돈만 들어가고, `받을 예정`인 돈은 받았어요를 누른 뒤에 합산됩니다. 비용은 기록한 날짜의 달에 바로 반영됩니다.
기록은 이 기기의 브라우저에만 저장되니, 기기를 바꾸기 전에 백업 파일을 받아 두세요.
