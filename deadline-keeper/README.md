# 🛡️ 기한지킴이 (Deadline Keeper)

디지털 라이프의 모든 데드라인(기프티콘, 구독료, 세금, 자동차 검사, 시험 접수, 회비 …)을 한 화면에서 관리하는 웹 앱입니다.
빌드 과정 없이 **HTML + Tailwind CSS(CDN) + Vanilla JS + Tesseract.js + LocalStorage** 만으로 동작합니다.

## 실행 방법

```bash
cd deadline-keeper
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 더블클릭해서 열어도 대부분 동작하지만, OCR(Web Worker)과 브라우저 알림은 `http://localhost` 이상의 환경에서 가장 안정적입니다.
첫 방문 시 오늘 날짜 기준 샘플 데이터가 자동으로 들어갑니다. 하단의 **전체 초기화**로 비울 수 있습니다.

## 📲 앱으로 설치하기 (PWA)

HTTPS 주소(GitHub Pages 등)로 열면 홈 화면에 앱으로 설치할 수 있습니다. 설치하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷이 없어도 실행됩니다.

- **Android (Chrome, 삼성 인터넷)**: 상단의 `📲 앱 설치` 버튼, 또는 브라우저 메뉴 → `앱 설치` / `홈 화면에 추가`
- **iPhone (Safari)**: 아래쪽 공유 버튼(□↑) → `홈 화면에 추가` (앱 화면 상단에 안내 카드가 표시됩니다)
- **PC (Chrome, Edge)**: 주소창 오른쪽의 설치 아이콘

앱 파일을 수정해 다시 배포할 때는 `sw.js`의 `VERSION` 값을 올려야 설치된 앱도 새 버전으로 바뀝니다.

## 기능 요약

| 영역 | 내용 |
| --- | --- |
| 대시보드 | 긴급 알림 배너(오늘 마감 / 기한 지남 / 리마인드 도달), 요약 카드(이번 달 총 고정 지출, 이번 주 마감 임박, 관리 중인 기한, 이번 달 완료) |
| 뷰 전환 탭 | ⏱️ 임박순 타임라인 · 🗂️ 카테고리별 폴더 · 📅 캘린더 뷰(반복 일정 예정 회차 표시) · 🏆 완료 아카이브 |
| 카드 | 이모지 + 대분류 태그(툴팁) + 세부 메뉴 태그, 굵은 항목명, D-Day 뱃지, 금액. 오늘 마감이면 빨간 테두리 + `🔥 오늘 안 쓰면 손해!` |
| 카테고리 | 기본 5개 대분류 × 추천 세부 메뉴 10개 + `[ + 직접 입력 ]`, 이름·이모지·색상·설명을 고르는 커스텀 대분류 무제한 생성 |
| 완료 처리 | 한 번만: 아카이브로 이동 / 반복(매주·매월·매년): 다음 주기로 마감일 자동 갱신(31일 → 말일 보정), 회차 기록은 아카이브에 누적. 모든 동작 `되돌리기` 지원 |
| 리마인드 | 항목별 당일 / D-1 / D-3 / D-7 선택 → 접속 시 배너, 🔔 버튼으로 권한을 주면 하루 한 번 브라우저 알림 |
| 📸 OCR | 항목 추가 모달의 `이미지로 자동 입력` → Tesseract.js(한국어+영어)로 브라우저 안에서 무료 인식 → 항목명·마감일·금액·카테고리 자동 채움 |
| 🔗 항목 공유 | 카드의 🔗 버튼 → 휴대폰 공유 창(카카오톡·문자 등) 또는 링크 복사. 받은 사람이 링크를 열면 미리보기 후 `내 목록에 추가`. 항목 정보는 주소의 `#` 뒤에 담겨 서버로 전송되지 않음 |
| 저장 | LocalStorage 영구 저장, JSON 백업 내보내기/불러오기, 여러 탭 간 동기화 |

## 파일 구조

```
deadline-keeper/
├── index.html          # 레이아웃, 모달, Tailwind 테마(컬러 팔레트) 설정
├── manifest.webmanifest # 앱 이름·아이콘·전체 화면 설정 (PWA)
├── sw.js               # 오프라인 실행용 서비스 워커
├── icons/              # 앱 아이콘 (192/512, maskable, apple-touch)
├── css/style.css       # 버튼·탭·카드·모달·토스트·툴팁 컴포넌트 스타일
└── js/
    ├── app.js          # 상태/저장, D-Day 계산, 렌더링, 완료·반복 로직, 알림, OCR 연동
    └── ocr-parser.js   # OCR 원문 → 마감일/항목명/금액/카테고리 추정 (Node에서도 실행 가능)
```

## OCR 동작 방식

1. 사진을 최대 1800px로 줄이고 흑백·대비 보정 (인식률·속도 향상)
2. Tesseract.js 스크립트와 `kor+eng` 언어 모델을 **버튼을 처음 누를 때만** CDN에서 내려받음 (이후 브라우저 캐시 사용)
3. `ocr-parser.js`가 원문을 분석
   - 마감일: `2026.12.31`, `2026-12-31`, `2026년 12월 31일`, `26.12.31`, `20261231`, `12월 31일` 인식. `유효기간·소비기한·까지·EXP` 같은 키워드가 붙은 날짜를 우선하고, `발행일·구매일` 날짜는 감점, `A ~ B` 기간은 끝 날짜 선택
   - 항목명: `상품명:` 같은 라벨 우선, 없으면 상단의 의미 있는 한글 줄 (글자마다 띄어진 OCR 결과는 붙여서 보정)
   - 금액: `합계·결제금액` 줄 우선, 없으면 `원` 표기 중 최댓값
   - 카테고리: 기프티콘/넷플릭스/고지서/도서관 등 키워드로 대분류·세부 메뉴 추정
4. 채워진 칸은 노란색으로 잠깐 강조되고, `인식된 원문 보기`에서 원문을 확인할 수 있음

모델 다운로드가 실패하거나 너무 오래 걸리면 오류 토스트를 띄우고 직접 입력하도록 안내합니다.
