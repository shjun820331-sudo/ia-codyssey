# 기한지기

생활 속 모든 기한을 한곳에서 챙기는 웹앱입니다. `index.html` 파일 하나로 동작하며 설치가 필요 없습니다.

## 실행
`index.html`을 브라우저로 열면 됩니다. 데이터는 브라우저(localStorage)에 저장됩니다.

## 챙길 수 있는 기한
| 분류 | 예시 |
| --- | --- |
| 식품 | 우유, 계란 유통기한·소비기한 |
| 구독·OTT | 넷플릭스, 유튜브 프리미엄 (매월 결제일 자동 계산) |
| 소프트웨어 | Microsoft 365, 한컴오피스(한글) |
| 쿠폰·기프티콘 | 카카오톡 선물, 할인쿠폰 |
| 화장품 | 개봉일 + 개봉 후 사용기한(PAO)으로 자동 계산 |
| 의약품 | 상비약 사용기한 |
| 포인트·마일리지 | 카드 포인트·항공 마일리지 소멸일 |
| 서류·면허 | 여권 만료, 운전면허 적성검사 |
| 자동차 | 보험 만기, 정기검사 |
| 계약·약정 | 휴대폰 약정, 전·월세 계약 만료 |
| 생활 교체 | 정수기 필터, 콘택트렌즈 (N일마다 반복) |
| 기타 | 도서관 책 반납 등 |

## 기능
- D-day 도장 표시: 기한 지남(빨강) / 곧 다가옴(노랑) / 여유(초록)
- 반복 기한: 매월·매년·매주·N일마다 → 다음 결제일·교체일 자동 계산
- 월 고정지출 합계 (연 결제는 12로 나눠 계산)
- 분류 필터, ‘챙길 것’ 모아보기, 검색
- 사용함/다 먹음/해지함 → 완료 목록으로 이동, 되돌리기 가능
- 추천 항목 버튼으로 빠른 입력
- 휴대폰 알림: 항목의 **알림** 버튼
  - **Google 캘린더에 추가**: 일정이 반복 설정과 함께 추가되고, 휴대폰 캘린더 앱이 알림을 보냄
  - **캘린더 파일(.ics) 받기**: 아이폰 기본 캘린더·삼성 캘린더용. 설정한 ‘며칠 전’과 당일 오전 9시에 알림 (내려받은 index.html에서만 가능)
  - ‘전체 항목 캘린더 파일(.ics) 받기’로 한 번에 등록
- 백업 · 불러오기 (JSON 복사/붙여넣기로 다른 기기로 이동)
