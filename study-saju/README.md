# 공부사주

사주(만세력)로 **타고난 공부 스타일, 대운·세운·월운으로 본 공부 흐름, 시험 전략, 진로·직업**을 보여 주고, 그 결과를 바탕으로 **AI(Claude)가 학년·고민·시대 흐름까지 함께 보며 상담**해 주는 웹 앱입니다.
학생 본인 모드와 학부모(자녀) 모드가 있고, 초등학생부터 고등학생·N수생까지 학년에 맞춰 내용이 달라집니다.
빌드 과정 없이 **HTML + CSS + Vanilla JS + LocalStorage**만으로 동작합니다.

## 실행 방법

```bash
cd study-saju
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages에 올리면 `/study-saju/` 주소로 휴대폰에서 바로 쓸 수 있고, 홈 화면에 앱으로 설치(PWA)할 수 있습니다.
앱 파일을 고쳐 다시 배포할 때는 `sw.js`의 `VERSION` 값을 올려야 설치된 앱도 새 버전으로 바뀝니다.

| 공부 스타일 | 5가지 공부 유형(이해·흡수형 / 표현·설명형 / 실전·성과형 / 계획·규율형 / 경쟁·자기주도형), 강점·함정, 학년별 공부법, 맞는 환경, 일간 기질. 학부모 모드에서는 대화법 추가 |
| 공부 흐름 | 대운(10년), 올해와 앞으로 2년의 세운, 월별 공부 흐름(집중기·유지·관리기)과 학사 일정, 시험별 전략 |
| 진로·직업 | 잘 맞는 계열 3개와 학과, 추천 직업 8개(32개 중 상대 비교, 미래 유망 표시), 학년별 진로 탐색 활동 |

## 계산 정확도

정확도는 계산 단계에서 결정되기 때문에, 사주 계산은 AI가 아니라 코드(`js/engine.js`)가 합니다.

- **절기 기준 연주·월주**: 입춘·경칩 등 절입 시각(분 단위)으로 해와 달을 나눕니다.
- **출생지 경도 보정**: 기본값은 경도 보정(서울 약 −32분, 부산 약 −24분). 정밀 설정에서 균시차까지 넣은 진태양시, 또는 보정 안 함을 고를 수 있습니다.
- **서머타임·표준시 변경**: 1948~1951, 1955~1960, 1987~1988년 서머타임과 1954~1961년 UTC+8:30 표준시를 브라우저의 시간대 데이터(Asia/Seoul)로 자동 반영합니다.
- **밤 11시~자정 출생**: 자시 통일(다음 날 일주, 기본값) / 야자시(그날 일주) 중 선택합니다.
- **한국 음력**: 계산 라이브러리는 중국 기준(UTC+8)이라, 1960년 이후는 합삭 시각을 한국 시간으로 다시 따져 초하루를 정합니다(예: 2027년 설날 한국 2/7, 중국 2/6). 윤달 배치가 두 나라에서 다른 드문 해는 반영하지 않으니, 가능하면 양력으로 입력하세요.
- 시간을 모르면 시주 없이 계산합니다.

테스트: `node tests/engine.test.cjs` (일주·절기 경계·서머타임·자시·한국 음력·대운 방향·학년별 시험 일정 25개)

## 해석 방식

`js/analysis.js`가 규칙으로 해석하고, 문장은 `js/knowledge.js`에 모여 있어 내용을 고치기 쉽습니다.

1. 오행 세력: 천간 1, 지지는 지장간 비율(본기 0.6·중기 0.3·여기 0.1 등)로 나누고, 월지는 2배
2. 신강/신약: 비겁+인성의 비율(52% 이상 신강, 38% 이하 신약)
3. 용신: 억부(강하면 식상·재성·관성, 약하면 인성·비겁)와 조후(여름생 수, 겨울생 화)를 함께 판단 → 희신·기신·구신
4. 운의 점수: 대운·세운·월운의 천간·지지 오행이 용신에 도움이 되는지, 일지·월지와 충·합인지로 집중기 / 유지 / 관리기를 나눔
5. 공부 스타일·진로: 가장 강한 십신 그룹과 두 번째 그룹의 조합, 용신 오행

숫자 기준은 단순화한 규칙이라 참고용입니다. 해석 문장이나 기준을 바꾸려면 `knowledge.js`와 `analysis.js`의 상수를 고치면 됩니다.

## AI 상담

- 정적 웹앱이라 서버가 없어서, 사용자가 **본인의 Anthropic API 키**를 넣으면 브라우저에서 Claude API를 바로 호출합니다. 키는 그 기기의 브라우저에만 저장됩니다. 공용 기기에서는 저장하지 마세요.
- 모델은 `claude-opus-5-5`(effort `medium`)이고, 답변은 스트리밍으로 받습니다. 최신 입시·직업 정보가 필요하면 웹 검색 도구를 최대 3번 사용합니다. 안전상 답변이 거절되면 서버가 자동으로 다른 모델로 다시 시도하는 fallback 옵션(`fallbacks: "default"`)을 켜 두었습니다.
- AI에게는 앱이 계산한 사주 요약(원국, 오행·십신 비율, 용신, 대운·세운·월운, 학사 일정)과 학년·고민·목표만 보내고, 사주를 직접 다시 계산하지 못하게 합니다.
- 단정·공포 표현, 합격 보장, 부적 권유를 금지했고, 위기 신호가 보이면 자살예방상담 109, 청소년상담 1388을 먼저 안내하도록 했습니다.
- 질문할 때마다 본인 계정에 API 사용료가 나갑니다.
- 여러 사람이 쓰는 서비스로 키우려면, API 키를 서버(예: Cloudflare Workers, Vercel 함수)에 두고 앱은 그 서버를 거쳐 호출하도록 바꾸는 것이 좋습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `js/vendor/lunar.js` | 절기·간지 계산 라이브러리 [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7 (MIT) |
| `js/engine.js` | 시간 보정, 한국 음력, 사주팔자·대운·세운·월운 계산 |
| `js/knowledge.js` | 공부 스타일, 운의 의미, 오행 보완, 학부모 대화법, 계열·직업, 학사 일정 |
| `js/analysis.js` | 오행·십신 세력, 신강/신약, 용신, 운의 점수, 공부 스타일·진로 산출, AI용 요약 |
| `js/counsel.js` | Claude API 상담(시스템 프롬프트, 스트리밍, 웹 검색, 오류 처리) |
| `js/app.js` | 화면, 저장(LocalStorage), 백업·불러오기 |

모든 정보는 이 기기의 브라우저에만 저장됩니다. 설정에서 JSON 백업을 받아 둘 수 있습니다.

> 사주는 타고난 경향을 보는 참고 자료입니다. 실제 성적과 진로는 노력, 환경, 선택이 훨씬 크게 좌우합니다.
